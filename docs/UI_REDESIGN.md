# Guided portfolio lab — October 2026

## Experience

The former long form/report has become a guided workspace. Build your mix uses a live allocation ring and stock legend, one-click saved example, an equal-weight shortcut, optional CSV import, and progressively disclosed date controls. A persistent navigation rail moves to Explore results or AI field notes once a report exists. Explore contains Overview, Risk & allocation, Compare mixes and AI tabs, with keyboard arrow navigation. Navigation does not calculate new numbers or call Gemini.

The visual direction uses warm paper, dark ink, mint and coral accents; locally rendered charts and graphics need no remote fonts/CDNs. Layouts adapt to desktop, tablet and mobile. The allocation ring displays input weights only, not predicted or simulated performance. Equal weighting changes only current weights and preserves the alternative; it is a construction shortcut, not a recommendation.

Financial calculations, date alignment, saved data, cache policy, Gemini model and stale-request protections are retained. All provider calls remain user initiated. Print includes all report views and refuses to present stale results as a current report.
