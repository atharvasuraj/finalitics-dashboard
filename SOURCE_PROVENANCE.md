# Source provenance and team credit

Finalitics restores and extends the collaborative KVGAI Tech internship prototype from https://github.com/OmkarShr/FINANCEKVGAI, via Atharva's fork https://github.com/atharvasuraj/FINANCEKVGAI. The inspected base is fc55e2930c8e2a0d43762f9b5122d365faf808cd.

May–July 2025 internship team: Atharva Suraj Krishnan, Kevin Felix Dcunha (nabujika), Omkar Shrikanth (OmkarShr). Work was collaborative without strict responsibility divisions; Kevin and Omkar wrote more original code. Commit counts are not used to assign ownership. October–November 2026 restoration, tests, data fixes, dashboard, Gemini interpretation and UI redesign are later work, not internship accomplishments.

This repository begins with a clean source snapshot because historical credential patterns were found in original Git history. The raw upstream history and original local checkout were preserved rather than rewritten. Credential patterns in published notebook copies are redacted; no downloaded prices or runtime secrets are included. Original source and attribution links are preserved. This new repository is not a claim of sole authorship of the original application and does not establish new licensing rights over the team's work.
